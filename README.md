# 🕊️ Sistema Integral Farmacia Espíritu Santo (Sucursal 19 de Julio)

Sistema de gestión farmacéutica, punto de venta (POS), control de medicamentos por código de barra, trazabilidad de lotes con caducidad FEFO, portal B2B para proveedores y administración financiera.

---

## 🚀 Características Principales

- **Punto de Venta (POS):** Venta rápida con lector de código de barra, cobro en efectivo y tarjeta, cálculo automático de cambio.
- **Trazabilidad FEFO (First-Expired, First-Out):** Priorización automática de lotes con fecha de vencimiento más próxima para evitar mermas.
- **Devolución con Justificación Obligatoria:** Escaneo de código de barras del medicamento y separación automática a cuarentena si el producto está caducado.
- **Portal B2B de Proveedores:** Enlace público para que laboratorios y droguerías consulten pedidos emitidos en tiempo real.
- **Finanzas & Arqueo:** Arqueo de caja, conciliación bancaria inteligente contra extractos y tablero de gastos operativos (OPEX) con cálculo de utilidades netas.
- **100% Responsive & Privado:** Acceso con login de seguridad por rol (Administrador, Farmacéutico, Cajero) y bloqueo instantáneo de terminal.

---

## 🛠️ Tecnologías

- **Framework:** Next.js (App Router) + React 19
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS (Temática Blanco y Verde Médico)
- **Íconos:** Lucide React

---

## 💻 Instalación y Ejecución Local

```bash
# Entrar a la carpeta frontend
cd frontend

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
npm run start
```

---

## ☁️ Despliegue en la Nube (Vercel / Netlify)

1. Conecta este repositorio en [Vercel](https://vercel.com).
2. Establece el directorio raíz (`Root Directory`) en: `frontend`
3. Presiona **Deploy**. ¡Listo en menos de 1 minuto!
